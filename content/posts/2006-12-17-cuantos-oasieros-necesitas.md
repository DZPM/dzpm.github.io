**¿Cuántos oasieros necesitas para cambiar una bombilla?**

![](/images/posts/cuantos-oasieros-necesitas/bombilla_rota.jpg)

*¡yo no he sido!*

- uno para darse cuenta de **que están a oscuras**
    - otro para darse cuenta de que el problema está en la bombilla, que no responde a *ping*s.
        - cuatro para tratar de resetear la bombilla. Por el camino, resetean la nevera, la calculadora, y la *memory card* de la playstation. Finalmente se resetea la bombilla, pero sigue sin funcionar
    - otro para darse cuenta que hay que cambiar la bombilla
- uno para decir que en sus tiempos no usaban bombillas, sino *velas de cera*, y que iluminaban más
    - tres para recordarle que los tiempos han cambiado
- otro para recordar **que están a oscuras**
- uno para enviar un link a un plano de una bombilla
    - otro para enviar un link a una caricatura que le hizo una vez a un profe, haciéndola pasar por la caricatura de una bombilla
    - otro para enviar un link a *hentai* de bombillas
    - otro para enviar un adjunto con la foto en alta resolución de una bombilla
        - otros cinco para enumerar los motivos por los que no se pueden mandar adjuntos a la lista, porque somos muchos y se quita ancho de banda
- tres para recordar que la semana que viene empieza la maquetación, y **necesitamos la bombilla**
- uno para decir que la culpa es del *apt-get*
    - uno para dudar que que alguien que usa *MacOS* sea capaz de usar el apt-get
        - dos para discutir de *BSD* vs *GPL*, y de por qué el kernel *Darwin* es libre o no
    - otro para recomendar *Windows Vista*
        - tres más para colgar links a meneame sobre los numerosos defectos de *Windows Vista*
            - uno para hacer lo mismo, pero con un link a *Fresqui*
                - cinco para decir "*OMG FRESQUI N00B!!!one!!one!!eleven!!*"
- uno para enviar un link de un vídeo de youtube sobre gente que rompe bombillas
    - diez para recordar que la lista de "ocio" existe para algo
- uno para señalar las faltas ortográficas de los anteriores
    - otro para señalar un error gramatical de este último
        - otro para decirle que él *hexkrive kmo kiere*
            - dos para colgar sendos links a "<span class="dead-link" title="Enlace roto: http://revistes.upc.es/wiki/HOYGAN">HOYGAN</span>" y a "<span class="dead-link" title="Enlace roto: http://revistes.upc.es/wiki/Analfaburro">analfaburro</span>"
- uno para decir que necesitará 4 hojas para su cómic
    - uno para hacer rimas con la palabra "*cuatro*"
    - dos para decirle que con 2 páginas le sobra
        - otro para decir que en la fiesta del fin de semana pasado se lió con 2 a la vez
    - cinco para diferenciar entre hoja/cara/página. Al final lo consiguen.
- un oasiero para recordar que la maquetación empieza mañana, y que **seguimos a oscuras**
    - otro para recordar que a oscuras no se puede maquetar
        - otro para decir que en sus tiempos se maquetaba con *OpenOffice.org* y con luz natural
            - uno para decir que los hombres de verdad maquetan con *LaTeX* y a la luz de las estrellas
                - otro para recordarle "*la de años que llevas en la FIB*"
                    - el de antes para decirle que "*no te pongas celosa, que tú también te los pegarás*"
- otro para decir que las bombillas con GNU/Linux no se funden
    - otro para recordarle que esa bombilla iba con GNU/Linux
        - el de antes para decir que, en ese caso, es culpa del hardware
            - cinco para discutir si funcionaría mejor con un *raid0* de bombillas o una bombilla *Raptor 10.000*
- otro para decir que no es culpa del hardware, sino que es culpa de Distorsió
    - otro para recordar, otra vez, aquella historia de *los telecos*, el *partido de fútbo*l, el *vaso de kalimotxo*, y la *regleta de enchufes de los ordenadores  
*
        - cuatro para decir que ahora nos llevamos bien con Distorsió, y para concluir que ahora la culpa es del Xollo
            - uno para decir que *"Oceanía siempre ha estado en guerra con Eurasia y aliada con Asia Oriental*", y destacar la buena tarea realizada por el *MiniVer.*
- un oasiero para decir que la maquetación termina mañana, y que **la bombilla es imprescindible**
    - otro para decir que no es tan grave, no hay *nada* que maquetar
        - otro para discutir acerca del concepto *"nada"*
- uno para decir que en los *backups* de la bombilla está todo el *pr0n* de Fulanito
    - diez para exigir el cambio inmediato de la bombilla, y que se restauren los *backups*
        - uno más, para especificar que no importa el orden en que se haga
- uno para darse cuenta de que ha salido una nueva versión de la bombilla
    - otro para menear la noticia
    - otro para ponerla a bajar
        - uno para grabar la ISO de la bombilla en un CD
            - y otro, que pasaba por ahí y se aburría, para instalarla
